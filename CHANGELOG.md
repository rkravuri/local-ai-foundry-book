# Change list

Every version of the book is listed here, newest first. The PDF of each version is on the [Releases](https://github.com/rkravuri/local-ai-foundry-book/releases) page.

How the versions are numbered:

- `1.0.1`, `1.0.2`, and so on: corrections to the first edition, such as typing errors, broken links, and small wording fixes.
- `1.1.0`, `1.2.0`, and so on: changes to the content of the first edition, such as updated dates for a regulation.
